# 奖励模型（Reward Model）

> 奖励模型（Reward Model, RM）是 RLHF 流程中的"裁判"——它学会给回答打分，为后续的 PPO 强化学习提供奖励信号。训练一个高质量的 RM 是 RLHF 成功的关键前提。本模块从 RM 的角色定位出发，深入讲解 Bradley-Terry 偏好模型、对比学习训练方式、评估方法，并讨论 reward hacking、过拟合等实际问题。
>
> 前置：[[偏好数据构建]] → 本模块（训练 RM）→ 后续可衔接 [[PPO]]

---

## 一、奖励模型的作用

### 1.1 RM 在 RLHF 中的位置

```
┌─────────────┐     ┌──────────────────┐     ┌─────────────┐
│  SFT 模型     │ ──→ │  训练 Reward Model │ ──→ │   PPO 优化    │
│  教模型怎么回答  │     │  学会判断回答好坏   │     │  用 RM 引导模型 │
└─────────────┘     └──────────────────┘     └─────────────┘
```

RM 的本质：输入（prompt, response）→ 输出一个**标量分数**，表示该回答的质量。

```
RM("如何提高睡眠质量？", "保持规律作息，睡前远离手机") → 0.87
RM("如何提高睡眠质量？", "你可以试试安眠药")           → -1.23
```

### 1.2 为什么需要单独训练 RM？

SFT 的 loss 是逐 token 的交叉熵，它只能衡量"像不像"，无法衡量"好不好"。RM 学习的是**全局质量信号**——它看完完整回答后给出一个整体评价，而不是逐 token 打分。

| 对比维度 | SFT | Reward Model |
|---------|-----|-------------|
| 学习目标 | 模仿标准答案的 token 分布 | 学习人类对回答质量的偏好 |
| 输入 | prompt + partial response | prompt + **完整** response |
| 输出 | 下一个 token 的概率分布 | 一个标量分数 |
| 训练数据 | (指令, 回答) 对 | (prompt, 好回答, 差回答) 对比对 |

### 1.3 RM 为 PPO 提供什么？

PPO 优化目标的核心是：

$$\max_{\pi_\theta} \mathbb{E}_{x, y \sim \pi_\theta}[r(x, y)] - \beta \cdot \text{KL}(\pi_\theta \| \pi_{\text{ref}})$$

其中 $r(x, y)$ 就是 RM 的打分。RM 提供的信号质量直接决定了 PPO 能否学到有用的策略。

`★ Insight ─────────────────────────────────────`
RM 并不直接告诉模型"应该怎么改"，它只提供一个标量信号。模型需要通过反复采样、比较、梯度更新来自己摸索"怎么做才能拿高分"。这就像给学生考试打分 vs. 给学生逐字批改——RM 给的是前者，PPO 需要自己从分数中提炼出改进方向。
`─────────────────────────────────────────────────`

## 二、Bradley-Terry 偏好模型

### 2.1 什么是 Bradley-Terry 模型？

Bradley-Terry 模型是一种经典的**成对比较**（pairwise comparison）概率模型，最早用于体育比赛排名（谁赢谁输的概率）。它回答一个核心问题：

> 给定两个选项 A 和 B，A 被偏好于 B 的概率是多少？

假设每个选项有一个"实力值" $r$，则 Bradley-Terry 模型定义：

$$P(A \succ B) = \frac{e^{r_A}}{e^{r_A} + e^{r_B}} = \sigma(r_A - r_B)$$

其中 $\sigma$ 是 sigmoid 函数。

### 2.2 用 Bradley-Terry 建模偏好

在 RM 中，每个回答 $y$ 对应 prompt $x$ 有一个"质量分数" $r(x, y)$。好回答被偏好的概率：

$$P(y_w \succ y_l \mid x) = \sigma(r(x, y_w) - r(x, y_l))$$

直觉：
- 如果 $r(x, y_w) \gg r(x, y_l)$，则 $P \approx 1$（好回答几乎肯定更好）
- 如果 $r(x, y_w) \approx r(x, y_l)$，则 $P \approx 0.5$（难分伯仲）
- 如果 $r(x, y_w) < r(x, y_l)$，则 $P < 0.5$（RM 认为差回答更好——模型还需要学）

### 2.3 从概率模型到损失函数

给定训练数据 $\{(x_i, y_{w,i}, y_{l,i})\}$，用最大似然估计（MLE）训练 RM：

$$\mathcal{L}_{RM} = -\mathbb{E}_{(x, y_w, y_l)} \left[ \log P(y_w \succ y_l \mid x) \right] = -\mathbb{E} \left[ \log \sigma(r(x, y_w) - r(x, y_l)) \right]$$

这就是 RM 的标准训练损失——本质上就是**让好回答的分数比差回答的分数更高**。

| 符号 | 含义 |
|------|------|
| $x$ | prompt（问题） |
| $y_w$ | 人类更偏好的回答（winner） |
| $y_l$ | 人类不太喜欢的回答（loser） |
| $r(x, y)$ | RM 对 (prompt, response) 的标量打分 |
| $\sigma$ | Sigmoid 函数，映射到 [0, 1] |

`★ Insight ─────────────────────────────────────`
Bradley-Terry 模型的巧妙之处在于：它不需要人类给出绝对分数（比如"这个回答值 85 分"），只需要相对排序（"A 比 B 好"）。这大幅降低了标注难度——人类做选择题比做填空题简单得多。这也是为什么偏好数据用"对比对"而非"绝对评分"。
`─────────────────────────────────────────────────`

## 三、Reward Model 的训练方式

### 3.1 架构设计

RM 基于 SFT 模型初始化，只需改动最后一层：

```
┌──────────────────────────────────────────┐
│           SFT 模型 backbone               │
│  ┌────────────────────────────────────┐  │
│  │        Transformer Layers           │  │
│  │   (权重从 SFT 模型继承，可微调)       │  │
│  └───────────────┬────────────────────┘  │
│                  ▼                        │
│  ┌────────────────────────────────────┐  │
│  │  Linear(hidden_size → 1, bias=False)│  │  ← 替换 token 预测头
│  └───────────────┬────────────────────┘  │
│                  ▼                        │
│              标量分数 r(x, y)              │
└──────────────────────────────────────────┘
```

关键实现细节：
- **取最后一个 token 的隐藏状态**作为整个序列的表示
- 需要正确处理 padding：找每个序列中最后一个非 padding token 的位置
- 输出头不加 bias（避免分数有偏移）

### 3.2 训练流程

```python
# 伪代码：RM 训练的核心循环
for batch in preference_dataloader:
    # batch 包含: prompt, chosen(好回答), rejected(差回答)

    # 1. RM 对好回答打分
    chosen_rewards = reward_model(prompt, chosen)    # r(x, y_w)

    # 2. RM 对差回答打分
    rejected_rewards = reward_model(prompt, rejected) # r(x, y_l)

    # 3. 计算 Bradley-Terry 损失
    loss = -torch.log(torch.sigmoid(chosen_rewards - rejected_rewards)).mean()

    # 4. 反向传播
    loss.backward()
    optimizer.step()
```

### 3.3 训练技巧

| 技巧 | 说明 |
|------|------|
| **从 SFT 模型初始化** | 比从头训练收敛更快，因为 SFT 模型已经理解语言 |
| **Loss 改进：padding masking** | 好回答和差回答长度不同时，只对比有效 token |
| **温度系数** | 有些实现会在 sigmoid 前加温度系数，控制梯度大小 |
| **从排名构造对比对** | 4 个回答排序 A>B>C>D，可展开为 6 个对比对 |
| **学习率** | 通常比 SFT 小（1e-5 ~ 5e-6），避免灾难性遗忘 |

### 3.4 从排名到对比对的转换

实际标注中，人类对 4 个回答排序（如 InstructGPT 的做法），而非直接给对比对。展开方式：

```
原始排名：A > B > C > D

展开为对比对：
  (A, B), (A, C), (A, D)
  (B, C), (B, D)
  (C, D)
共 6 对（C(4,2) = 6）
```

等价关系：排名越远的两个回答，对比对提供的信息越强（A vs D 的梯度信号比 B vs C 更大）。

`★ Insight ─────────────────────────────────────`
从排名展开为对比对时，距离越远的 pair（如最好 vs 最差）包含的偏好信号越强。有些实现会对排名远的 pair 给予更高的权重，因为 RM 更容易从这些"极端对比"中学习。但这也会导致数据不平衡——排名靠前的对比对远少于排名靠后的，需要适当处理。
`─────────────────────────────────────────────────`

## 四、如何评估 Reward Model 的准确性

### 4.1 核心指标：准确率（Accuracy）

最直观的评估方式：在测试集上，RM 对好回答给出的分数是否高于差回答？

$$\text{Accuracy} = \frac{1}{N} \sum_{i=1}^N \mathbb{1}[r(x_i, y_{w,i}) > r(x_i, y_{l,i})]$$

即：RM 认为好回答的分数更高的比例。

| 准确率范围 | 含义 |
|-----------|------|
| > 70% | RM 质量较好，可以用于 PPO |
| 60-70% | 勉强可用，PPO 可能需要更多 KL 约束 |
| < 60% | RM 不可靠，继续训练或换数据 |

### 4.2 其他评估维度

| 指标 | 说明 | 怎么算 |
|------|------|--------|
| **准确率** | 好回答分数 > 差回答分数的比例 | $\mathbb{1}[r_w > r_l]$ |
| **AUC-ROC** | 衡量 RM 区分好/差回答的能力 | ROC 曲线下面积 |
| **Kendall Tau** | RM 的排序与人类排序的一致性 | 排名相关系数 |
| **校准度** | RM 输出的分数是否具有实际概率含义 | $P(r_w > r_l)$ vs 实际一致率 |
| **跨 prompt 泛化** | 在未见过的 prompt 类型上的表现 | 分 prompt 类别统计 |

### 4.3 评估的陷阱

1. **测试集必须与训练集分布一致**：如果测试集的 prompt 类型和训练集完全不同，准确率没有意义
2. **准确率高 ≠ RM 好**：RM 可能在训练集分布内准确，但被 PPO exploit（reward hacking）
3. **需要人工校准**：定期用新的人类标注数据检查 RM 是否仍然可靠

## 五、面试重点

### Q1：Reward Model 在 RLHF 中的作用是什么？

> RM 是 RLHF 流程的"裁判"，它学习人类对回答质量的偏好，输入 (prompt, response) 输出标量分数。PPO 强化学习以 RM 的分数作为奖励信号，引导策略模型学会生成更高质量的回答。RM 的质量直接决定了 PPO 能否学到有用的策略。

### Q2：Bradley-Terry 模型是什么？为什么用它训练 RM？

> Bradley-Terry 是一种成对比较概率模型：$P(A \succ B) = \sigma(r_A - r_B)$。它把人类的相对偏好（"A 比 B 好"）转化为概率，用最大似然估计来训练 RM。选择它的原因是：(1) 只需要相对排序，不需要绝对评分，标注门槛低；(2) 数学上优雅，loss 就是 $\log \sigma(r_w - r_l)$；(3) InstructGPT 论文验证了其有效性，成为工业界标准。

### Q3：Reward Hacking 是什么？怎么缓解？

> Reward Hacking 指策略模型学会了"讨好"RM 而不是真正变好。例如 RM 偏好长回答，策略模型就生成冗长无内容的文字；RM 偏好某些特定短语，策略模型就反复使用。
>
> 缓解方法：
> 1. **KL 惩罚**：限制策略模型偏离参考模型的程度
> 2. **定期更新 RM**：用策略模型的新输出重新标注、重新训练 RM
> 3. **Ensemble RM**：多个 RM 取平均，减少单个 RM 的偏好漏洞
> 4. **人工校准**：定期检查 RM 的分数是否仍与人类判断一致

### Q4：Reward Model 的过拟合问题是什么？

> RM 的训练数据规模通常远小于预训练数据（几万到几十万对比对），容易过拟合。过拟合的表现：
> - 训练集准确率很高（>90%），但测试集准确率低
> - RM 对某些特定模式过度自信，对其他模式束手无策
> - PPO 优化后，模型学会了 RM 在训练集上的"套路"，但这些套路在真实人类评估中并不好
>
> 缓解方法：早停（early stopping）、正则化、数据增强、增大训练数据规模。

### Q5：RM vs DPO 各自的适用场景是什么？

> | 维度 | RM + PPO | DPO |
> |------|----------|-----|
> | 流程复杂度 | 高（需训练 RM + PPO 循环） | 低（直接监督学习） |
> | 显存需求 | ~4 倍 SFT | ~2 倍 SFT |
> | 训练稳定性 | PPO 不稳定，超参敏感 | 稳定 |
> | 上下限 | 上限可能更高（RM 可复用、可迭代） | 上限受偏好数据质量限制 |
> | 适用场景 | 资源充足、需要 RM 复用（多场景打分）、追求极致效果 | 资源有限、快速迭代、单一场景 |
>
> 核心区别：RM 是一个**可复用的打分器**，训好后可以在多个场景使用（在线过滤、数据筛选、多轮 PPO）；DPO 是一次性的"策略模型训练"，训完就没有独立的打分能力了。

### Q6：训练 RM 时，选择最后一个 token 的隐藏状态有什么直觉？

> 因为 LM 是自回归的，最后一个 token 的 hidden state 经过了完整序列的 attention，理论上包含了整个回答的语义信息。这是 causal LM 特有的——每个位置只看它之前的信息，所以只有最后一个位置"看到了"全部内容。类似地，某些实现也会尝试取所有 token hidden state 的均值，但实验中通常取最后一个 token 效果更好。

## 六、总结

**RM 训练一句话**：用 Bradley-Terry 模型把人类的"偏好排序"转化为对比学习任务，基于 SFT 模型初始化，替换输出头为标量打分，用 $\log \sigma(r_w - r_l)$ 训练。

**三个关键要点**：
1. RM 给 PPO 提供标量奖励信号，其质量决定了 PPO 的上限
2. Bradley-Terry 只需相对排序，不需要绝对评分——降低标注门槛
3. RM 的评估以准确率为主，但要注意过拟合和 reward hacking

**与其他模块的衔接**：偏好数据 → 训练 RM → 用 RM 分数驱动 [[PPO]]。如果跳过 RM，可以直接用 [[DPO]] 完成对齐。
